Powered By

Every technology chosen for a reason. Click any card to explore.

Next.js 14

App Router with server components for optimized builds and instant page loads.

The backbone of BrewBeats — Next.js 14's App Router gives us server-side rendering for fast first paint and client components for the interactive studio.
  • Server components reduce JS bundle size
  • API routes handle AI model proxying
  • File-based routing with zero config
  • Incremental static regeneration ready

Tone.js

Web Audio framework powering 50+ synthesized instruments with real-time FX.

The audio engine. Tone.js wraps the Web Audio API with musical abstractions — synths, samplers, effects chains, and precise scheduling.
  • PolySynth, MonoSynth, FMSynth, MetalSynth engines
  • Shared reverb & delay buses for performance
  • Real-time FFT analyzer for visualizer
  • Offline rendering for WAV export

Zustand

Lightweight state driving sessions, undo/redo, and audio engine sync.

One store to rule them all. Zustand manages composition state, chat history, transport controls, mixer settings, and session persistence.
  • 970-line store with computed selectors
  • 10-deep undo/redo stack per session
  • Auto-save with 2s debounce to localStorage
  • Session create/switch/rename/delete

Tailwind CSS

Utility-first styling with a custom "dusk coffee" design system.

A bespoke design language. The "dusk coffee" theme pairs coffeehouse warmth with recording-studio moodiness across 11 semantic tokens.
  • Custom palette: espresso, roast, caramel, cream, dusk, gold
  • Semi-transparent panels with backdrop-blur
  • Custom scrollbar and range slider theming
  • Responsive breakpoints for mobile-first

Framer Motion

Smooth animations for streaming reveals, transitions, and the visualizer.

Every interaction feels alive. Framer Motion powers the track-streaming animations, panel transitions, and the music-reactive studio visualizer.
  • Track cards stream in one-by-one during generation
  • Note shimmer and glow keyframes
  • Fullscreen hover-zone panel reveals
  • Cubic-bezier easing throughout

AI / LLM

Multi-model AI that converts prompts into structured compositions.

The brain. A streaming AI backend converts conversational prompts into structured JSON compositions with tracks, notes, and effects.
  • 50+ model support via configurable endpoint
  • SSE streaming for real-time generation feedback
  • Context window management with auto-compaction
  • Patch-based updates for iterative edits
